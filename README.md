# SS Chat Server

Real-time private messaging backend for SS Chat Android App.

## Technology

- Node.js
- Express.js
- Socket.IO
- PostgreSQL
- JWT Authentication

## Features

- Automatic SS User ID
- User Registration
- User Login
- Real-time Messaging
- Temporary Message Storage
- Automatic Message Deletion
- Offline Message Delivery
- Socket Authentication

## User ID Format

SS0001
SS0002
SS0003

## Message Expiration

Messages automatically expire after 24 hours.

## Installation

npm install

## Development

npm run dev

## Production

npm start
